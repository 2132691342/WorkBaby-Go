# 内置运行时

位置：`internal/runtime/`（`manager.go` 解压与 PATH 注入、`runtimes_test.go` 安全边界）+ `scripts/copy-runtimes.ps1`（随包分发）。

## 为什么内置

MCP server 与技能脚本普遍依赖 `node` / `npx`、`python` / `uvx`、`powershell`。要求用户自装并配好 PATH 会显著抬高使用门槛，且版本不可控。WorkBaby 随包分发这三个运行时，开箱即用、版本一致。

## 组成

`runtimes/` 目录随包分发三个压缩包（Node / Python / PowerShell），构建后由 `copy-runtimes.ps1` 复制到产物旁。应用首启（或检测到缺失 / 版本不匹配）时解压到：

```
{home}/runtimes/node/…  python/…  powershell/…
```

## 生命周期

- **解压时机**：启动后台首跑，不阻塞主流程；`rt.Ensure()` 同步等待完成，保证后续 MCP 子进程的 PATH 注入生效。解压失败仅告警，不阻断启动（此时退化为依赖系统 PATH）。
- **PATH 注入**：`BinDirs()` 返回各运行时的可执行目录，注入到 MCP 子进程与技能脚本的执行环境。
- **幂等**：已存在且版本匹配则跳过；目录可整棵删除后自动重建。

## 安全边界

解压实现强制两条约束（有测试守护）：

1. **路径穿越拒绝**：压缩包内条目解析后的目标路径必须落在解压根内，含 `..` 或绝对路径的条目直接拒绝。
2. **限额**：条目数量与总解压字节数设上限，防解压炸弹。

## 校验

`GET /meta/runtime` 返回各运行时的就绪状态与路径，设置页据此展示；`{home}/logs/` 的启动摘要包含运行时解压结果。
