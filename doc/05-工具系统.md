# 工具系统

位置：`internal/tool/` 及各子包。所有「模型能调用的动作」都是实现统一契约的工具；`tool/` 不依赖 harness / api / service / wails，工具自身不落库。

## 工具契约

```go
type Tool interface {
    Name() string
    Description() string
    Schema() ToolSchema                       // JSON Schema
    RiskLevel() RiskLevel                     // readonly | write_local | exec | network | destructive
    Execute(ctx context.Context, args json.RawMessage) ToolResult
}
```

- `ToolResult`：Content（回填 LLM）、Data（结构化，前端展示）、Err、Meta（耗时 / exitCode）、Refused（审批拒绝 = 非故障，不推进失败熔断）。
- 可选接口：`MetaProvider`（声明式元信息）、`ActivityProvider`（按参数自述时间线动词）、`RiskClassifier`（按参数给 per-call 风险与审批描述）。
- `ToolMeta`：ReadOnly / Destructive / PathParams / TimeoutSec / MaxResultChars / UIHint / Group / Category（info/edit/exec/network/irreversible）/ ActivityDesc；未声明时按风险级与工具名前缀兜底推导。
- `Registry`：注册即编译 schema（非法或重名即失败）、`Get` / `List` / `Unregister`（MCP 卸载）、`AllReadOnly`（只读并行裁决）、`SelfCheckSchema` 启动期自检。
- 参数校验：用 JSON Schema（draft 2020-12，支持 $ref / allOf / oneOf / pattern / 数值范围 / additionalProperties）；空 schema 直接通过。

## 风险分级与权限模式

- 风险级：`readonly` / `write_local` / `exec` / `network` / `destructive`。
- 会话权限模式：`restricted` / `default` / `auto_edit` / `yolo`。
- 裁决矩阵（默认决策）：

| 模式 | readonly | write_local | exec | network | destructive |
|---|---|---|---|---|---|
| restricted | allow | deny | deny | deny | deny |
| default | allow | ask | ask | ask | ask |
| auto_edit | allow | allow | ask | ask | ask |
| yolo | allow | allow | allow | allow | allow |

- 策略门：先查显式规则（allow / ask / deny，支持 glob）——精确名优先、其次最长 glob；无规则回退矩阵默认。yolo 下连命令级裁决一并跳过。
- 按参数裁决：exec / run_skill_script 按本次命令给风险——白名单内安全命令免审，白名单外或危险正则命中仍弹审批。
- 装配侧显式放行（default 下本会 ask 的）：exec / run_skill_script / delegate_task / run_workflow（命令级裁决仍生效）、websearch / webfetch / http、knowledge_search / doc_reader / todo、file_write / archive_manager / memory_write（工作区沙箱内本地写）。

## 审批门

- 触发：策略门 ask 且未显式放行时转人工。
- 两档风险：`needs_approval`（可恢复；同命令本进程内批准过一次免审，可「本会话允许」）；`irreversible`（不可逆，**每次都问、永不免审**）；`input_required` 为补充输入，非安全审批。
- 流程：发审批事件后阻塞等待决策，超时视为拒绝；决策发审批完成事件；会话级放行只对可恢复档生效。
- 持久化与恢复（durable pause）：未决请求落 `approval_records`；`Pending()` 返回未决快照，前端刷新与重启后恢复；启动把遗留 pending 的决策窗口重武装 24h，**重启后决策即从检查点续跑原 run**——续跑重放的同一调用按已决记录快速放行/拒绝（consumed 防重复免审）；同会话新 run 启动清掉遗留挂起。
- 「本会话允许」授权持久化（`approval_grants` 表）：跨重启生效；产生它的 run 以 error/cancelled 收尾时自动回滚；设置页（高级）可随时撤销（`GET/POST /chat/approval-grants`）。
- 单层闸门：护栏链裁决后置 ctx 标记，exec / skillrun 内部据此跳过自有审批，消除双层重复询问。
- `Approver` 接口定义在 `tool` 包，实现在 service 层。

## 目录信任与工作区沙箱

- 信任三态：`allow` 直行 / `ask` 询问（未登记目录默认）/ `deny` 永不执行。沿祖先链就近上溯——信任某目录即信任其下全部子目录；未命中任何祖先恒为 ask（fail-closed，不落库）。
- 恒信任根（会话工作区树、全局工作区、知识库、附件、内置运行时等）：工具默认就在其中干活，纳入询问只制造噪声。流程：解析 → ask 则问审批 → 批准后落盘 allow；未注入审批门时 ask 按拒绝处理。
- 工作区沙箱 `.workbaby/`：绑定工作区时建立并写 `.gitignore`（`*`）让整树对 Git 不可见。子目录：`scripts/`、`output/`、`cache/`、`tmp/`、`memory/`、`snapshots/`、`skills/`；工作区根视为只读输入源，系统级数据不进工作区。
- 路径越界拦截：相对路径拼到根、绝对路径必须落在根内（`filepath.Rel` 防 `../` 穿越）；命中敏感目标拒绝；archive 同样根限定 + zip-slip 防护。
- exec cwd：显式传 cwd 时含 `..` 一律拒绝；解析后不在工作区根（含 .workbaby 子树）内拒绝；未绑定工作区时放行。

| `file_read` | readonly | 读工作区文本文件并登记读态 |

| `exec` | exec | 参数数组直跑（无 shell 拼接），白名单 basename + 危险正则拦截 |
| `webfetch` | network | 抓网页提取正文，返回有上限 |
| `websearch` | network | 搜索（免 Key 引擎），结果数有上下限 |

## 结果治理

- 通用截断：按工具声明的结果上限（有全局缺省）做 rune 安全截断并标注。
- 结果分型：`ToolMeta.UIHint`（diff / memory / workflow…）随 tool_result 事件与消息块下发（`ui_hint`），前端显式差异化渲染（diff 着色），内容嗅探仅作流式期兜底。
- exec 输出双端保留：限流写入器保留头部 + 尾部，中间丢弃并计数（保证子进程不因管道写满阻塞）。
- 检索 `.gitignore` 感知：读工作区根与检索起点的 `.gitignore`（`!` 反向、目录锚定、`**`），命中跳过；固定跳过 `.git` / `.workbaby` / `node_modules` / IDE 目录与二进制文件。
- 写前必读护栏：`file_read` 登记本轮 run 已读文件，`file_edit` 对已存在文件校验已读，否则拒绝——把「凭记忆改文件」堵在工具层；作用域为 run。

## 工具启用/停用

- 启停开关持久化在 system_settings，设置页可改。
- 暴露过滤：按开关与白名单过滤后转 LLM 工具定义；显式配置优先，未配置时纯函数分组默认停用（避免大量工具淹没模型），其余默认启用。
- 工具定义预算与折叠激活：定义超出上下文预算的部分不再整体塞给模型也不静默丢弃——折叠为 `tool_search` 虚拟工具按需激活（名称/描述子串检索，单次至多激活 8 个），激活的工具下一轮起进入请求并放行执行；激活态为 run 内语义。
- exec 白名单运行时读取，每次执行实时生效。
- MCP 工具：随 server 启停动态注册/注销（重名冲突跳过不覆盖）。

## 不变量

- 所有文件与 exec 路径受工作区根约束，越界与敏感目标一律拒绝。
- 不可逆操作每次必问、永不免审；「记住允许」只对可恢复档生效。
- 未登记目录 fail-closed（ask），无审批门时按拒绝处理。
- 单一执行闸门：护栏链已裁决的工具内部不再二次审批。
- 拒绝（未暴露/越权/审批拒绝）非故障，不推进失败熔断，模型可换路续跑。
