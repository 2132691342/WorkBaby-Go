# 桌宠

一个常驻桌面的形象层：独立置顶小窗与聊天页悬浮体两种形态，形象可替换，表情随 Agent 运行状态变化。

## 数据模型

| 表 | 主键 | 字段 |
|---|---|---|
| pet_configs | user_id（全局单行） | enabled、mode、sprite_id、position_x/y、scale、气泡开关与时长、聊天背景与不透明度/模糊、click_through |
| pet_sprites | id | name、file_path（磁盘绝对路径）、format、frame_count、is_builtin |

- 首启播种：内置形象在启动时落盘并注册（幂等），配置为空时默认选中，开箱即有形象，无需用户上传。
- 自定义形象：支持上传单帧或多帧图片（frame_count 决定帧数），可删除非内置形象。

## 形态与状态

- 两种形态：`pet`（独立置顶小窗）与 `main`（聊天页内悬浮体），切换即改变窗口形态与定位。
- 形象与聊天头像同源：聊天消息里的助手头像使用同一 sprite，保持一致视觉。
- 形象格式以文件头 magic number 判定（`.png` / `.jpg` / `.gif` / `.webp`），不信任扩展名；多帧（GIF）按帧播放。

### 状态机

`pet.Controller` 是纯内存状态机，不依赖 Wails，状态变更经 `onChange` 回调由 api 层转发前端。

| 状态 | 含义 |
|---|---|
| `idle` | 空闲（默认初值） |
| `working` | Agent 正在跑 run |
| `happy` | run 正常收尾，展示 3 秒后自动回 `idle` |
| `sleeping` | 用户长时间无操作（30 分钟） |

事件 → 状态映射：

| 事件 | 迁移 |
|---|---|
| `agent.run.start` | → `working` |
| `agent.run.done` | → `happy`，3s 后自动回 `idle`（仅当仍处于 happy） |
| `agent.error` | → `idle` |
| `user.idle.30min` | → `sleeping` |
| `user.active` | → `idle` |

相同状态的重复事件不触发回调（去抖），避免前端重复渲染动画。

## 点击穿透（Windows）

桌宠形态下窗口是矩形，透明留白会挡住下层窗口。开启配置 `click_through` 后：

1. 前端 `PetDesktop.vue` 采集可见交互元素（`.pet-card` / `.pet-bubble` / `.pet-chat`）的包围盒，乘 `devicePixelRatio` 并外扩 8px（抵消卡片漂浮动画），去抖后上报；
2. 后端 `pet.ApplyHitRegion` 用 `CreateRectRgn` + `CombineRgn(RGN_OR)` 合成区域，`SetWindowRgn` 施加到本进程可见主窗口（`EnumWindows` + PID 匹配，不依赖窗口标题）；
3. 区域外像素不接收鼠标事件，直接落到下层窗口；聊天气泡/面板显隐、缩放变化、窗口 resize 都会重算，退出桌宠形态或离开页面则清空区域。

取舍：用**包围盒并集**而非逐像素 alpha 掩码——卡片本身是半透明玻璃底，逐像素会挖掉可读区域；矩形并集已能把真正空白的留白交出去，且无需把 sprite 解码进 Go。空列表一律「整窗可交互」（宁可多挡一点，也不把用户锁在点不动的状态）。非 Windows 平台为 stub 空实现。

## 事件

状态与形态变化经事件总线下发（前端 `scope=pet` 订阅 SSE）：`pet:state`（idle / happy / working / sleeping）、`pet:show`、`pet:hide`。

## 端点

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /pet/window/click-through | 设置命中区域（body: enabled + rects[]，窗口客户区物理像素） |
| GET | /pet/state | 当前状态（情绪 / 动作，驱动形象动画） |
| GET | /pet/config | 配置 |
| POST | /pet/config/update | 更新配置（位置、缩放、气泡、背景等） |
| GET | /pet/sprites | 形象列表 |
| POST | /pet/sprites | 新增形象 |
| POST | /pet/sprites/:id/delete | 删除形象（内置不可删） |
| POST | /pet/window/:mode | 切换形态（pet / main） |

## 不变量

- 配置全局单行，切换形态与位置持久化，重启后恢复。
- 内置形象只读；播种幂等，重复启动不产生重复记录。
- 状态变化只由 run 事件驱动，不自行轮询业务数据。
