# 桌宠

位置：`internal/pet/`（配置 / 形象 / 状态机）+ `internal/api/api_pet.go`（窗口形态）+ 前端 `components/pet/`。

## 形态

1. **桌宠小窗**：主窗缩到 260×300、置顶、无系统按钮，前端切到 `/pet/desktop` 渲染形象 + 气泡 + 迷你聊天。位置与主窗位置分别记忆，切换时还原。
2. **聊天页悬浮陪伴体**（`PetCompanion.vue`）：抠好背景的形象浮在输入框上方，随会话状态切换姿态（idle 浮动 / thinking 加速摆动 / sad 垂头去饱和），点击随机台词，可召唤与收起（偏好持久化）。
3. **聊天头像**：形象同时作为助手头像（与桌宠同一 sprite 来源）。

## 形象资产

- 存储：`{home}/sprites/{id}.{ext}` + `pet_sprites` 表；内置吉祥物首启播种（`//go:embed`），配置未选形象时默认选中它。
- 上传：前端经文件对话框选路径 → 后端 `UploadPetSprite` 读文件（magic 校验 png/webp/gif/jpg，≤5MB）落盘并注册。
- **图片编辑**：前端 `ImageCropper.vue`（Canvas 零依赖）支持裁剪、任意角度旋转、水平 / 垂直翻转、缩放与**自动抠图**（四角均值取背景色，容差内 alpha 归零、边界软过渡）。本地图由后端 `ReadLocalImage` 代读成 data URL（WebView 不允许读 `file://`），编辑结果经 `SavePetSpriteImage` 以 PNG（保留 alpha）保存，抠出的形象即可透明悬浮。

## 配置

单行配置 `pet_configs`（字段级 patch 更新）：开关、形态模式、形象、位置、缩放、气泡开关与时长、聊天背景 / 透明度 / 模糊。

## 状态机

`Controller` 由 chat run 事件驱动：

```
idle ──agent.run.start──► working ──agent.run.done──► happy（3s 后回 idle）
                 agent.error ──► error 态
```

状态经 `pet:state` 事件推给前端，驱动形象动作与气泡文案。

## 迷你聊天

桌宠小窗内的输入框复用全局 chat store，但固定使用独立的「桌宠对话」会话，流式回复直接进小窗面板——桌宠不只是摆件，是能直接对话的入口。
