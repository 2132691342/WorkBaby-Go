# 前端架构

位置：`frontend/src/src/`。Vue 3 + TypeScript + Vite + Element Plus + Tailwind CSS 4。

## 应用骨架

```
main.ts            入口：主题先于 mount 应用（防首帧闪烁）、全局异常拦截
App.vue            布局壳：标题栏（自绘）+ 侧栏 + 路由出口 + 启动引导
router/            路由表（chat / home / 设置各页 / 桌宠 / 任务）
stores/            Pinia：chat / pet / skills / folders / files / …
api/               双主机 HTTP 层：client / http / stream / bootstrap / contract
components/
  chat/            会话主界面（输入框 / 消息 / 时间线 / 工作区面板 / 变更 / 任务中心）
  composer/        输入框子件（斜杠命令 / @ 提及 / 技能选择器 / 参数 / 队列 / 上下文）
  pet/             桌宠窗口与陪伴体
  common/          通用件（图标 / 图片编辑器 / 命令面板）
  genui/           GenUI 内联渲染
  settings/ …      其余能力域页面
i18n/              中英文案字典（key 完整性有测试守护）
```

## 双主机引导

```
bootstrapServer()
  1) Wails 绑定 GetServerPort()   ← 同步取值，无时序窗口（首选）
  2) app:ready 事件 + 轮询兜底     ← 事件是即发即忘的，可能早于监听器注册
  3) localStorage('wb.serverPort') ← 纯浏览器 dev 兜底
→ initApi(port) → 契约版本校验（/meta/contract）→ 挂载业务视图
```

启动失败显示可见错误态而不是白屏。

## HTTP 层约定

- `apiGet` / `apiPost` 统一处理 `{code, message, data}` 信封；`code !== 0` 抛 `Error(message)`，错误码随异常透传。
- SSE：`/api/v1/events?scope=chat&runId=…`；`scope` 决定接收的事件前缀（chat / task / workflow / pet / app）。
- Wails 绑定（`@/wailsjs/go/main/App`）只用于系统能力：对话框、本地图片读取、剪贴板、窗口控制。

## 状态管理与流式管线

```
SSE 事件 ─► normalize（事件名 → 类型化事件）
        ─► ChatStreamDecoder（纯函数：事件 → StreamEventUpdate）
        ─► StreamEventBatcher（一帧一渲染，先增量后终态）
        ─► chat store refs ─► StreamingBubble / MessageList
```

- 解码器是纯函数且有单测；批处理把高频增量合并到动画帧，避免逐 token 重渲染。
- `chat:done` 后立即拉权威快照替换流式气泡；`chat:gap`（重放窗口失效）转全量回补。
- 工具调用过程落 `message_blocks`，历史消息完整还原执行时间线。

## 组件设计约定

- **输入框**保留原生 `textarea`：中文 IME 组合、自增高、`@` / `/` 触发解析都依赖原生事件。触发解析基于**光标位置**而非行尾，保证中文标点后触发、中间插入也正确。
- 每个浮层（斜杠命令 / 提及 / 技能选择器 / 模型 / 参数）独立成组件，键盘导航（↑↓ / Enter / Esc）与点击外部关闭统一实现。
- 提示反馈统一走 `composables/useToast`（成功 / 提示用 ElMessage，错误用 ElNotification），不散落裸调用。
- 折叠容器用受控状态 + `max-height` 过渡，不用原生 `<details>`（避免瞬时塌陷的观感）。

## 主题与样式

- `style.css` 全局 token（`--wb-*`）+ `wb-ui.css` 原型组件样式 + `themes.css` 明暗两套；代码块配色走 `--wb-c-*` 变量，明暗共用一份 token 规则。
- Tailwind 用于布局与间距，语义色与圆角一律引用 token，避免硬编码色值。

## Markdown 渲染

`MarkdownRenderer.vue`：markdown-it 单例（流式 / 终态两档配置）+ DOMPurify 消毒 + 终态异步增强（代码块装饰 / KaTeX / Mermaid 按需动态加载）。长代码用 `max-height` 滚动限高而非折叠，保证内容始终可见；仅超长 dump 走原生 `<details>` 折叠。

## 桌宠与多形态

`App.vue` 监听 `pet:show` / `pet:hide` 事件做路由切换（进桌宠前记忆原路由），窗口尺寸 / 置顶 / 位置由 Go 侧控制，前端只负责按形态渲染不同视图。
