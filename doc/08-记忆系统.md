# 记忆系统

三层记忆，落点与生命周期各不相同：

| 层 | 载体 | 生命周期 |
|---|---|---|
| 短期 | 会话历史（chat_messages） | 上下文窗口，由聊天层的上下文重建与压缩负责（记忆层不重复实现滑窗） |
| 长期 | `MEMORY.md`（按会话） | 追加式增量沉淀，跨轮次保留 |
| 情景 | `memory_episodes` + FTS5 | 每次成型一条摘要 + 对话副本 |
| 语义 | `memory_facts` | `(subject, key)` 唯一，覆盖更新 |
| 程序 | `memory_procedures` | `name` 唯一，覆盖更新 + 成功/失败计数 |

## 落点约定

绑定工作区 → `<workspace>/.workbaby/memory/`；未绑定 → `{home}/memory/{sessionID}/MEMORY.md`。落点跟随会话工作区，与快照、沙箱同源。

## 形成（写）

- run 结束后异步沉淀（独立超时，不阻塞回复），由记忆能力在 `Capture` 通道触发。
- 形成策略是**确定性打分**，不调 LLM：按触发条件（消息数量阈值、时间间隔、显式触发等）评估是否成型，输出情景 / 语义 / 程序三类提案；负反馈（明确表达不喜欢）一票否决，避免把一次性否定当成习惯沉淀。
- 写入语义：情景追加并同步 FTS5（同事务）；语义与程序按唯一键覆盖更新，FTS 索引先删后插避免陈旧条目；长期记忆按会话追加增量文本。
- 模型也可主动写入：`memory_write` 工具（kind=long_term / fact）。

## 检索（读）

- **关键词检索**：FTS5（trigram 分词，中文可用），BM25 排序；查询不足 3 字符（trigram 最小窗口）时零命中，自动退化为子串扫描并按相关度重排（不按时间排序）。
- **融合召回**：跨三类统一召回，按分数融合，带时间衰减（越旧权重越低）与近重复合并，并设相关性下限（低于下限不注入，避免噪声）。
- **注入**：每轮 run 前，长期记忆尾部（上限 4000 rune）与召回命中（默认 TopK 5）作为 system 的记忆段注入；知识库召回独立成段。

## 端点

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /memory/search | 全文检索 |
| GET | /memory/recall | 跨三类统一召回（融合分） |
| GET | /memory/episodes | 情景列表（可按会话） |
| POST | /memory/episodes | 手动写入情景 |
| POST | /memory/episodes/:id/delete | 删除情景（含 FTS 行） |
| GET | /memory/facts | 语义列表 |
| POST | /memory/facts | 写入/覆盖语义 |
| POST | /memory/facts/:id/delete | 删除语义 |
| GET | /memory/procedures | 程序列表 |
| POST | /memory/procedures | 写入/覆盖程序 |
| POST | /memory/procedures/:id/delete | 删除程序 |
| GET | /memory/stats | 三类计数（记忆中心与仪表盘） |
| GET | /memory/long-term/:id | 某会话长期记忆全文 |

## 不变量

- 短期窗口不在此层实现：上下文重建只由聊天层负责，避免两套滑窗口径不一致。
- 情景写入与 FTS 索引同事务；覆盖更新不留陈旧索引。
- 召回有下限与时间衰减，不注入低相关噪声。
- 长期记忆落点随工作区，删会话不清空全局记忆文件。
