# 17 内置运行时

## 定位

Skill 脚本（node / python / powershell）执行环境的离线打包：首次使用解压到 `dataHome/runtimes/`，SkillRunTool 把其 bin 目录注入 PATH。

## 设计要点

- **离线优先**：release 包内含 `runtimes/node-v20-x64.zip` / `python-3.12.tar.gz` / `powershell-7-x64.zip`，不依赖用户机器已装 node / python
- **懒解压**：首次启动 SkillRunTool 检测 runtime 不存在则解压；已存在跳过
- **PATH 注入**：SkillRunTool.Execute 在 fork 解释器前把 runtime bin 目录 prepend 到 PATH
- **版本锁定**：manifest 声明 major.minor（如 `node 20.x`），解压到 `{dataHome}/runtimes/node-20-x/`；跨 major 升级需更新二进制
- **Windows 优先**：当前实现只跑 Windows（CLAUDE.md §1 锁定 Windows）

## 核心契约

### `runtimes/manifest.json`

```json
{
  "runtimes": [
    {
      "id": "node",
      "version": "20.x",
      "archive": "node-v20-x64.zip",
      "binary": "node.exe",
      "ext": ".js"
    },
    {
      "id": "python",
      "version": "3.12",
      "archive": "python-3.12.tar.gz",
      "binary": "python.exe",
      "ext": ".py"
    },
    {
      "id": "powershell",
      "version": "7.x",
      "archive": "powershell-7-x64.zip",
      "binary": "pwsh.exe",
      "ext": ".ps1"
    }
  ]
}
```

### 内置运行时服务（`internal/runtime/`）

```go
type Service struct { ... }
func (s *Service) BinDirs() []string              // 当前已解压 runtime 的 bin 列表（PATH 注入用）
func (s *Service) Ensure(ext string) (string, error) // 确保该 ext 的 runtime 已解压，返回 binary 路径
```

### 数据目录布局


### SkillRunTool.Execute（运行时路径注入）

```go
ext := path.Ext(scriptFile)                              // .js / .py / .ps1
binPath, _ := runtimes.Ensure(ext)                       // 确保已解压并取 binary
tmpDir, _ := os.MkdirTemp("", "wb-skill-*")
defer os.RemoveAll(tmpDir)
tmpScript := filepath.Join(tmpDir, "main"+ext)
os.WriteFile(tmpScript, scriptContent, 0o644)

cmd := exec.Command(binPath, tmpScript, args...)
cmd.Env = os.Environ()
cmd.Env = append(cmd.Env,
    "PATH="+strings.Join(append(runtimes.BinDirs(), origPath), string(os.PathListSeparator)))
cmd.Dir = workspaceRoot
out, err := cmd.CombinedOutput()
```

## 关键流程

### 首次启动 node 脚本

```
1. SkillRunTool.Execute 收到 `script=".js"`
2. runtimes.Ensure(".js") → 查 manifest → archive 不存在 → 解压 node-v20-x.zip → 写 {dataHome}/runtimes/node-20-x/
3. 返回 node.exe 路径
4. tmpDir 创建 + 写临时脚本
5. cmd = exec.Command(node.exe, tmpScript, args...)
6. cmd.Env.PATH prepend runtimes/node-20-x/
7. 执行 → CombinedOutput
```

### 已存在 runtime

```
Ensure(".py") → 目录已存在 → 直接返回 python.exe
```

## 约束

- 仅 Windows（archive 是 zip / tar.gz 含 .exe / .dll）；Linux / macOS 留给后续
- 不替代用户已装的 node / python：永远用内置的（PATH 前置覆盖），避免环境不一致
- 二进制签名：发布前用项目证书给 exe + Skill 脚本 zip 签名（可选）
- Skill 脚本超时独立于 runtime 解压超时；解压失败 → SkillRunTool 直接报错
