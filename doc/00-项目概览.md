# WorkBaby 项目概览

> 一份文件读懂 WorkBaby 的定位、技术栈、架构与核心能力。后续 `doc/01`～`doc/17` 是各模块的详细设计。

## 定位

WorkBaby 是面向本地单用户的桌面 AI Agent 客户端。基于自研轻量 Agent Harness，支持多 LLM 供应商、工具调用、MCP 协议、本地知识库与 RAG、长期记忆、工作流引擎、可交互桌宠。所有数据落本地 SQLite，无云端依赖。

## 技术栈

| 层 | 选型 |
|---|---|
| 语言 | Go 1.25.x（单 module） |
| 桌面壳 | Wails v2.12.x（Windows） |
| 业务 API | gin ^1.10.x（127.0.0.1 随机端口） |
| 流式事件 | SSE（`/api/v1/events?scope=chat&runId=…`） |
| ORM | GORM + glebarez/sqlite（pure-Go，无 CGO） |
| 数据库 | SQLite 3.45+（WAL + FTS5 trigram） |
| 配置 | Viper ^1.19.x（YAML + ENV） |
| 工具/MCP | 自研 stdio MCP 客户端（spec 2025-06-18） |
| 定时 | robfig/cron/v3 |
| 测试 | testing + testify |

前端：Vue 3 + TypeScript + Vite + Element Plus + Tailwind CSS v4（自建 `wb-*` 设计 token）。

## 架构总览

**双主机架构**：业务 API 走 gin HTTP（127.0.0.1 随机端口注入前端），Wails 绑定仅保留系统能力（文件对话框、剪贴板、托盘、打开外部链接）。前端同时通过 SSE 订阅事件、通过 Wails 调用系统能力；前端事件不重复编排。

**Agent 循环**（`internal/harness/runner.go`）：
1. 装配 system + 历史（能力注入 / 压缩）
2. 调 LLM（per-turn 统计、独立 thinking 通道）
3. 解析 tool_calls → 工具护栏链（暴露校验 → 路径信任 → 策略门 + per-call 风险 + 单层审批 → 注入防护 → 执行 panic 隔离）
4. 回填 tool 结果 → 累积 / 检查点 / 续跑
5. 终止判定（end_turn / 停滞 / max_turns / token_budget）

**统一工具护栏链**：
- `tool.Gate`：工具级 allow/ask/deny × SessionMode（restricted / default / auto_edit / yolo）
- `tool.RiskClassifier`：exec / skillrun 把命令级风险（白名单、危险正则）通过 `ClassifyArgs` 上移
- `tool.GuardChain` ctx 标记：runner 裁决完毕后标记，工具内部跳过自有审批 → 单层闸门

**事件 / 落库 / 重放**：
- 事件类型 `chat:*` / `workflow:*` / `pet:*` / `app:*` 经 `event.Bus` → SSE hub → 前端（Wails 事件桥仅桥接 `app:*`）
- 每条事件带单调 seq 写入 `RunEventLog` 环形缓冲；断线重连按 `Last-Event-ID` 重放（首次连接也补发全部缓存事件）；缓冲滚动覆盖则推 `chat:gap`
- 会话消息落 `chat_messages`（assistant/user/tool）+ `message_blocks`（工具过程）+ `token_usages`（per-turn）+ `agent_checkpoints`（resume）

## 核心能力

| 模块 | 说明 |
|---|---|
| Agent Harness | 自研 ReAct 循环、停滞熔断、截断重发、优雅停止、检查点 resume |
| LLM 适配 | OpenAI / Anthropic / Ollama 兼容协议；7 种 thinking 方言探测；上游错误归一化 |
| 工具系统 | 25+ 内置工具（exec / file / web / memory / workflow 等）+ 30 个 functools 纯函数工具（整组默认禁用，设置页可开启）；exec 内置 Windows 命令白名单 + 破坏性正则；文本工具调用兜底 |
| MCP | stdio 客户端（MCP 2025-06-18 spec）；Server 注册 / 启停生命周期；崩溃自动注销工具 |
| Skill | SKILL.md 技能（触发词路由 + 可选脚本）；按 Skill 名动态注入 system + 工具白名单 |
| 记忆 | 长期 delta（episodes）/ 语义 fact / 程序 procedure 三层；确定性打分形成（dislike 一票否决）；FTS5 + 短词兜底召回（会话上下文重建由 chat.toLLMMessages 唯一负责） |
| 知识库 / RAG | 文档入库（分块 → FTS5 trigram → 检索） |
| 工作流引擎 | DAG 执行器（并行层、超时、取消）；LLM 节点；Cron 触发 |
| 定时 / 通知 | Cron 调度；webhook / email 通道 |
| 桌宠 | 透明无边框悬浮窗；sprite + 表情 + 动画；LLM 表情映射 |
| 前端 | 双栏布局；流式聊天；任务中心；桌宠窗口 |

## 设计优势

1. **真正的离线 / 单用户**：所有数据本地 SQLite；本地文件系统访问有路径信任与白名单双层保护；gin 仅绑回环地址
2. **多 LLM 兼容**：结构化 tool_calls 与文本工具调用双通道；7 种 thinking 方言探测；上层协议归一化屏蔽厂商差异
3. **可靠流式**：per-turn token 统计不冒充累计；事件 seq 单调递增；断线重连按 Last-Event-ID 重放；环形缓冲滚动自动 gap 通知
4. **配对安全的上下文管理**：压缩（Micro / Auto）以「assistant(tool_calls) + 连续 tool 结果」不可拆为硬规则；DB 加载再剥孤儿 → 三层防护杜绝上游 400
5. **可恢复长任务**：检查点工具步骤记忆化（`tool:name+args` 幂等键）；resume 不重放副作用；待审批挂起 run 而非失败硬终止
6. **协议层防护**：错误分类为机器可读 kind + 可操作提示；文本工具调用防注入（参数里的伪标记检测）；审批拒绝是结构化回执而非错误
7. **纯 Go / pure-Go SQLite**：无 CGO；交叉编译友好；部署仅一个 exe + 本地数据目录

```
├── main.go / app.go              Wails 入口 + App 结构体
├── internal/
│   ├── api/                      HTTP 业务 handler + 文件服务

│   ├── service/                  业务编排（chat / task / workflow / …）
│   ├── harness/                  Agent 内核（runner / 压缩 / 检查点）
│   ├── llm/                      LLM 适配 + 方言探测
│   ├── tool/                     工具 / 策略 / 审批接口
│   ├── mcp/                      stdio MCP 客户端
│   ├── memory/                   三层记忆
│   ├── rag/                      知识库
│   ├── workflow/                 工作流引擎
│   ├── cron/ channel/ pet/ tray/ 定时 / 通知 / 桌宠 / 托盘
│   ├── event/ db/ domain/ pkg/ repo/ config/ 基础设施

```
