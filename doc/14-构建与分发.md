# 构建与分发

## 构建

```powershell
wails build            # 产出 build/bin/WorkBaby.exe（前端 npm run build + go build + 嵌入）
wails dev              # 开发模式：vite dev server + Go 热重启
```

- 前端产物固定输出到 `frontend/dist`，由 `//go:embed all:frontend/dist` 嵌入二进制（单文件分发的前提）。
- 构建后钩子执行 `scripts/copy-runtimes.ps1`，把 `runtimes/` 下的 Node / Python / PowerShell 运行时包复制到产物目录旁边（见 17）。
- `wails.json` 配置了文件关联：`.md` / `.txt` / `.pdf` 双击即用 WorkBaby 打开并交给 AI 处理。

## 安装包

`build/windows/installer/` 内的 NSIS 脚本生成 `WorkBaby-amd64-installer.exe`：安装主程序、注册文件关联、写入卸载信息。

## 单实例

启动时通过 Windows Mutex 检测 + 本地 TCP IPC 保证单实例：

- 二次启动（含文件关联打开）把文件路径转交主实例后退出；
- 主实例收到路径后唤起主窗并发 `app:open-file`，前端导入文件 → 新建会话 → 以「阅读总结」发起处理。

## 运行数据

- 数据根：`%APPDATA%/WorkBaby`（可用 `WORKBABY_HOME` 重定向，便于便携部署与备份）。
- 首启自动建目录、生成主密钥、迁移 DB、播种内置桌宠形象。
- 卸载不删用户数据（目录保留），重装即恢复。

## 版本与契约

- `/meta/version` 返回应用版本；`/meta/contract` 返回前后端契约版本号，前端启动时比对，不一致显式报错（避免静默 404）。
- 日志写 `{home}/logs/`，启动摘要（工具数 / 技能数 / MCP 就绪数）一并落盘，便于排查。
