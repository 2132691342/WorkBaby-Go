# WorkBaby 界面原型 · 交付说明

单文件自包含原型：`prd/WorkBaby-UI-Prototype.html`（190 KB，无外部依赖，双击即可打开）。

## 覆盖范围

| 组 | 画面 |
|---|---|
| 主导航 | 概览、聊天、工作流、任务、定时任务、仪表盘 |
| 资源 | 记忆、知识库、技能、MCP 服务、更多资源 |
| 工作区 | 文件、文件夹、工具、通知通道、桌宠空间 |
| 系统 | 文档、设置 |
| 二级画面 | 工作流 DAG 编辑器（工作流页「编辑图」进入）、桌宠悬浮窗（桌宠空间「打开桌面悬浮窗」进入） |

共 20 个可切换画面，侧栏 18 个入口。

## 视觉依据

全部沿用 `frontend/src/src/themes.css` 的 `wb-*` 令牌，未发明新色：

- 底色分层 `--wb-bg #f7f7f5` → `--wb-surface #ffffff` → `--wb-surface-2 #fafaf8`
- 单主色靛蓝 `#4f46e5`（仅用于交互态与关键强调），琥珀 `#d97706` 作点缀
- 圆角 8 / 12px，1px 内描边，阴影仅用于浮层
- 字体栈 `'Inter', 'PingFang SC', 'Microsoft YaHei', system-ui`；等宽 `JetBrains Mono` 系列

## 交互

- 侧栏点击切换画面，标题栏同步显示路由；左下角可收起侧栏
- 聊天页：思考面板折叠/展开、工具卡逐条展开（args + result）、右侧「变更 / 任务 / 工作区」三页签切换
- 记忆中心：长期 delta / 语义 fact / 程序 procedure 三页签
- 设置：模型 / 通道 / 搜索 / 外观 / 高级 / 关于六页签

## 数据来源

文案与字段取自 `doc/01`～`doc/17` 设计文档与 `frontend/src/src/components/**` 实际实现，包括：

- 工具风险分级与 25 个内置工具清单（doc/05）
- 三层记忆、Formation 四个触发器（doc/08）
- 工作流节点类型与取消语义（doc/10）
- cron 表达式、通道 outbox 与重试策略（doc/11）
- 桌宠状态机与 IPC 绑定（doc/12）
- SSE 事件、上下文占用、审批策略（doc/07、doc/13）

## 说明

原型为静态走查稿，未接后端；尺寸按 1280×800 以上桌面窗口设计（最小宽度 1180px）。
