# 15 · 构建与分发

生产构建、Windows 安装包、内置运行时、体积优化与数据目录。
日常开发流程见 [`16-开发流程与命令.md`](16-开发流程与命令.md)。

## 1. 生产构建

```bash
wails build                            # → build/bin/WorkBaby.exe
wails build -ldflags "-s -w" -trimpath # 标准优化
wails build -nsis                      # 追加生成 Windows 安装包
```

产物：`build/bin/WorkBaby.exe` + `build/bin/runtimes/`。postBuildHook（`scripts/copy-runtimes.ps1`）把根目录 `runtimes/` 双向拷贝：
- `build/bin/runtimes/` — 供 `build/bin/WorkBaby.exe` 直接运行（Manager.LocateBundledDir 同级查找）；
- `build/windows/runtimes/` — NSIS 打包输入（`project.nsi` 的 `File /r "..\runtimes"`）。

钩子会按 `manifest.json` 校验（manifest 或任一归档缺失 → 立即失败，杜绝残缺安装包），每次先清空目标再拷贝，避免旧版本残留。

## 2. Windows 安装包

```bash
winget install NSIS.NSIS
wails build -nsis   # → build/bin/WorkBaby-amd64-installer.exe
```

安装包包含 `runtimes/` 目录（Node / Python / PowerShell 压缩包 + `manifest.json`），与 EXE 同目录：

```
安装目录/
├── WorkBaby.exe
└── runtimes/
    ├── node-v24.18.0-win-x64.zip
    ├── python-3.12.13-win-x64.tar.gz
    ├── powershell-7.5.2-win-x64.zip
    └── manifest.json
```

NSIS 使用 `File /r "..\runtimes"` 写入安装目录；缺少 `manifest.json` 或任一归档时，构建钩子会直接失败。

## 3. WebView2 分发策略

Win11 / Win10 1903+ 已内置。老系统 `-webview2 download`（在线引导）或 `-webview2 embed`。

## 4. 内置运行时（node / python / powershell）

Node / Python / PowerShell 压缩包与 `manifest.json` 一同进安装包（`build/bin/runtimes/`），NSIS 通过 `File /r "..\runtimes"` 写入安装目录；首次启动时由 `runtime.Manager.Ensure()` 解压到 `{home}/runtimes/{id}/{version}/`，后续执行工具时 PATH 仅对子进程前置。

完整设计（manifest 契约 / zip-slip 防护 / 版本隔离 / PATH 注入 / 升级路径）见 [`18-内置运行时.md`](18-内置运行时.md)。

## 5. 体积优化

| 手段 | 效果 |
|---|---|
| -ldflags "-s -w" | -20~30% |
| -trimpath | 去编译机路径 |
| 前端 manualChunks | 减小 embed 资源 |
| 依赖克制 | SQLite 用 glebarez pure-Go |

目标：Windows amd64 便携 EXE 尽量控制体积；安装包目标不再写死 30MB，因为 Node、Python、PowerShell 运行时已随安装包分发，当前完整安装数据约 200MB 以上。

## 6. 代码签名

Windows 用 OV/EV 证书 + signtool 签 EXE 与安装包。自用阶段可不签名。

## 7. 应用数据目录

```
{home}/db/workbaby.db          SQLite 主库（WAL）
{home}/config.yaml             Viper 配置（含加密主密钥）
{home}/model.json / mcp.json   配置文件源
{home}/runtimes/{id}/{version} 内置运行时
{home}/workspaces/{sid}/       会话工作区 + MEMORY.md
{home}/memory/episodes/        情景记忆快照
{home}/checkpoints/{sid}/      Agent 检查点
{home}/skills/ · sprites/ · media/ · exports/ · logs/
```

**便携版**：检测 EXE 同级 `portable.txt`，数据目录改为 EXE 同级 `data/`。

## 8. 故障排查速查

| 现象 | 排查 |
|---|---|
| wails dev 启动报错 | `wails doctor` |
| 前端拿不到 serverPort | 检查 `OnStartup`/`OnDomReady` 是否都发送 `app:ready` |
| API 404 | 检查 api base 端口；后端 gin 是否启动 |
| SSE 断连 | 检查心跳；事件 runId 过滤 |
| SQLite locked | WAL + busy_timeout=5000 |
| 安装目录缺运行时 | 检查 NSIS 的 `File /r "..\runtimes"` 和 installer 构建产物 |
| 用户目录缺运行时 | 检查日志、manifest、用户 HOME，以及 node.exe / python.exe / pwsh.exe |
| 启动白屏 | F12 console；检查 `booting/bootError` 和 dist 嵌入 |
