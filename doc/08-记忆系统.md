# 08 记忆系统

## 定位

`internal/memory/` 实现三层记忆：**短期上下文**（harness.messages，已在 harness 文档）+ **长期 delta**（memory_episodes）+ **语义/程序记忆**（memory_facts / memory_procedures）。

## 设计要点

- **三层各司其职**：短期 = 本轮+历史；长期 delta = 跨会话可检索的事件摘要；语义/程序 = 结构化知识（"用户偏好简洁回答" / "工具流程：websearch→file_write"）
- **Formation 规则**：每轮 run 结束按 4 子规则对 transcript 打分（关键词 / 偏好匹配 / 动作密度 / 明确调用）；**dislike 一票否决**（用户在消息中表达不喜欢则任何候选都丢弃）
- **FTS5 检索**：`memory_episode_fts` 虚拟表 + trigram 分词器（中文友好）；search 按相关度倒序 + 时间衰减
- **写入路径**：`memory_write` 工具 / `CaptureAll` 自动捕获；统一仓储 `MemoryRepository`

## 核心契约

### 数据库表

| 表 | 列 | 说明 |
|---|---|---|
| `memory_episodes` | `id, session_id, run_id, role, content, ts, score, source` | 长期 delta（每条事件摘要） |
| `memory_facts` | `(subject, key)` 唯一 · `value, confidence, source, ts` | 语义记忆（同 key 覆盖而非新增） |
| `memory_procedures` | `id, name, steps[], source, ts` | 程序记忆（工具链模板） |

### Formation 触发器

```go
type FormationTrigger func(transcript []llm.Message, priorEpisodes []Episode) (candidates []Candidate, err error)
```

| Trigger | 命中条件 |
|---|---|
| `triggerByKeywords` | 出现"记住/下次/以后/偏好/总是..." |
| `triggerByUserPreference` | 用户表达偏好（句式 + 正反情感词） |
| `triggerByActionDensity` | 一轮内多次工具调用（>3）= 高密度动作序列 |
| `triggerByExplicit` | 模型主动调用 `memory_write` 工具 |

`dislike` 命中 → 整个 transcript 标记 `disliked: true`，所有 trigger 返回空。

### 检索 API

```go
type SearchQuery struct {
    Text    string  // FTS5 查询
    TopK    int     // 默认 10
    MinScore float64 // 最低相关度
    Since   int64   // unix ms 起点
}
type MemoryService interface {
    Search(ctx, q SearchQuery) ([]Episode, error)        // FTS5 + score
    ListFacts(ctx, topK int) ([]Fact, error)
    WriteFact(ctx, subject, key, value string, confidence float64) (Fact, error)
    WriteProcedure(ctx, name string, steps []string) (Procedure, error)
    AppendLongTerm(ctx, sessionID, delta string) error
}
```

## 关键流程

### CaptureAll（每次 run 结束自动跑）

```
for each capability.Capture:
  candidates = candidate.transcript(user/assistant turns)
  if dislike in transcript: skip
  else:
    episodes = formationTriggers.filter(candidates)
    MemoryRepository.AppendLongTerm(batch)
  publish chat:memory 事件（前端可选 UI 展示）
```

### Search（向 LLM 注入长期记忆）

```
harness.Preload → memory.Search(query=RunState.LastUserInput)
  → FTS5 match('episodes', query) + BM25 score
  → 截取 TopK
  → 注入为 ContextPiece{Key:"memory", Title:"长期记忆", Body:episodes}
  → 排在 system 与工作区之后、Skill 之前
```

### memory_write 工具路径

```
model calls memory_write(content="用户偏好深色主题"):
  MemoryWriteTool.Execute → Writer.AppendLongTerm(episode)
  → 立即对后续轮次可见（FTS5 已索引）
```

## 约束

- 同 `(subject, key)` 的 fact 调用 `WriteFact` 走 upsert（不新增行）
- episode 文本中 `...</think>` 自动剥离（`LongTermDeltaStripsThink`），纯推理消息整行不入档
- 检索结果按 score desc + ts desc 二级排序
- FTS5 使用 `trigram` 分词器（unicode61 对中文退化）—— 重建或迁移时必须保留该选项
