# 08 · 记忆系统

定义 `internal/memory/`：五层记忆（短期 / 长期 / 情景 / 语义 / 程序）+ 形成策略 + FTS5 统一召回。
目标：助手「越用越懂你」——会话内记得住，跨会话忘不了，经历能沉淀。

---

## 1. 体系

```
Short-Term（短期）
  滑动窗口：chat_messages 最近 N 条 completed
  持久化：DB（chat_messages 表本身）

Long-Term（长期）
  每会话一个 MEMORY.md：摘要 + 关键事实
  持久化：{home}/workspaces/{sid}/MEMORY.md

Episodic（情景）
  每次对话的压缩摘要 + 全文快照
  持久化：memory_episodes 表 + FTS5 + 文件快照

Semantic（语义）
  用户偏好 / 事实（memory_facts 表，subject+key 唯一覆盖；FTS5 索引）

Procedural（程序）
  验证过的操作步骤（memory_procedures 表，name 唯一覆盖）
```

## 2. 文件结构

```
internal/memory/
├── service.go     # 五层记忆聚合 Service
├── short_term.go  # 短期滑动窗口（chat_messages）
├── long_term.go   # 长期记忆（MEMORY.md）
├── episodic.go    # 情景记忆（memory_episodes + FTS5 + 快照）
├── semantic.go    # 语义记忆（memory_facts + FTS5 索引）
├── procedural.go  # 程序记忆（memory_procedures）
├── formation.go   # 形成策略（确定性打分，不调 LLM）
└── recall.go      # RRF 统一召回
```

## 3. 接口

```go
// internal/memory/service.go
func (s *Service) ShortTerm(ctx, sessionID string, opts ShortTermOpts) []llm.Message
func (s *Service) LongTerm(ctx, sessionID string) string

```

## 4. 短期记忆

- 只取 `completed` 状态，pending / failed / cancelled 不进模型上下文；
- 按 seq 倒序取最近 N 条，再反转恢复正序；还原 tool 消息。

## 5. 长期记忆

- 读：每次 run 启动全量加载 MEMORY.md（典型 < 10KB）；
- 写：run 完成异步追加，格式 `## 日期\n\n内容`；
- 超过 100KB 提示用户整理（不自动截断）。

## 6. 情景记忆

- 写入：形成策略评分 ≥ 0.10 → memory_episodes 落库 + FTS5 + 文件快照；
- 检索：FTS5 trigram 检索 summary，中文友好；
- FTS5 虚拟表（启动期创建）：

```sql
CREATE VIRTUAL TABLE memory_episodes_fts USING fts5(
    episode_id UNINDEXED, summary, tokenize = 'trigram'
);
```

## 7. 形成策略（FormationPolicy）

**确定性打分，不调 LLM**——在 run 完成的异步路径执行。

```go
var DefaultTriggers = map[string]float64{
    "EXPLICIT_REMEMBER":   0.55,  // 「记住」「remember」
    "PREFERENCE_DETECTED": 0.40,  // 「我喜欢」「I prefer」
    "MULTI_STEP_SUCCESS":  0.35,  // 多步工具全部成功
    "CORRECTION":          0.30,  // 用户纠正
    "TOOL_SUCCESS":        0.20,  // 工具成功
    "TURN_COMPLETE":       0.15,  // 对话完整
    "USER_DISLIKE":        -1.0,  // 用户不满 → 抑制
}
```

阈值：Episodic 0.10 / Semantic 0.25 / Procedural 0.35。语义抽取「偏好 / 记住」事实；程序抽取「≥ 3 次工具调用」流程。`USER_DISLIKE` 一票否决。

## 8. 统一召回（RRF 融合）

三源（episodic FTS5 / semantic FTS5 / procedural 子串）并发召回；`rrfMerge`：score = Σ 1/(k + rank)，k=60。

长期记忆不参与 RRF——每次 run 全量注入 system prompt。

## 9. 与 Agent 的集成

```go
// chat service 发送时：
//   ShortTerm + LongTerm + Recall → 注入 system prompt
// run 完成后异步：
//   Evaluate → 达标则写 Episode / Fact / Procedure + LongTerm delta
```
