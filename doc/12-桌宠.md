# 12 桌宠

## 定位

`internal/pet/` 实现悬浮桌宠：透明无边框独立窗口，渲染用户 sprite（PNG/SVG），与聊天共用头像来源。

## 设计要点

- **独立 Wails 窗口**：无边框 + 透明背景 + 置顶 + 可拖拽；不抢主窗口焦点
- **头像来源与聊天统一**：`pet_configs.sprite_id → /files/sprites/{id}`，加载失败回退内置品牌 SVG
- **表情映射**：agent 状态（`IDLE / WALKING / CLICKED / THINKING / SPEAKING`）→ sprite 切帧
- **IPC 控制**：`pet.move(dx,dy)` / `pet.toggleMode()` / `pet.show()` / `pet.hide()`；`PetMove` / `PetToggleMode` 为 Wails 绑定
- **2.5s 轮询**：`GET /api/v1/pet/state` 驱动 sprite 表情动画（前端只拉，不推送）

## 核心契约

### 数据库表

| 表 | 列 | 说明 |
|---|---|---|
| `pet_configs` | `id, enabled, sprite_id, mode` | 单条（当前桌宠配置） |
| `pet_sprites` | `id, name, file_path, size, mime, ts` | 用户上传的 sprite 列表 |

### PetConfigDO

| 字段 | 说明 |
|---|---|
| `id` | 固定 `"default"`（单实例） |
| `enabled` | 桌宠是否显示 |
| `sprite_id` | 当前使用 sprite（→ `/files/sprites/{id}`） |
| `mode` | `follow`（跟随机型表情）/ `static`（固定表情） |

### PetSpriteDO

| 字段 | 说明 |
|---|---|
| `id` | ULID `SPRITE_` |
| `name` | 用户命名 |
| `file_path` | 本地路径（用于 `/files/sprites/{id}` 服务） |
| `mime` | `image/png` / `image/svg+xml` / `image/gif` |

### API

| 端点 | 方法 | 说明 |
|---|---|---|
| `/api/v1/pet/config` | GET / PUT | 当前配置 |
| `/api/v1/pet/sprites` | GET / POST (上传) / DELETE | sprite 列表 |
| `/api/v1/pet/state` | GET | 桌面侧轮询：mode + 当前 agent 状态 |

### Wails 绑定

```go
func (a *App) PetMove(dx, dy float64) error     // 拖拽位移
func (a *App) PetToggleMode() (string, error)  // 切换 follow/static
func (a *App) PetShow() / PetHide() error      // 显示/隐藏桌宠窗口
```

## 关键流程

### 桌宠窗口拖拽（pointer 事件）

```
PetDesktop.vue pointer-down → onPointerMove (rAF 节流) → PetMove(dx, dy)
  → handler.PetMove → runtime.WindowSetPosition(window, x+dx, y+dy)
  → 边界夹紧（不出屏）
  → double-click → PetToggleMode（follow ↔ static）
```

### 表情轮询

```
setInterval(2500ms):
  resp = GET /api/v1/pet/state
  sprite = pickByMode(resp.state)  // THINKING → 思考表情；SPEAKING → 说话表情...
  img = `${base}/files/sprites/${sprite}`
  onerror → 回退内置 brand.svg
```

### Sprite 上传

```
PetConfigPanel upload button → OpenFileDialog → save file to {dataHome}/sprites/{id}.png
  → pet_sprites.Insert
  → previewURL updates
```

## 约束

- 桌宠窗口始终在主窗口之前（`AlwaysOnTop`）但不抢焦点
- 拖拽增量走 rAF 节流，60fps 下不发多余 IPC
- sprite 文件路径经 `/files/sprites/{id}` 服务，**仅本机 127.0.0.1 可访问**（同 gin 绑定的回环）
- 桌宠关闭/打开不退出应用，仅切换窗口可见性
