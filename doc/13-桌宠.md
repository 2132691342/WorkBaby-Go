# 13 · 桌宠

`internal/pet/` 与前端 `PetSpaceView.vue` / `PetDesktop.vue`：桌面宠物（单窗口形态切换 + sprite + 状态表情 + 拖拽交互）。

---

## 1. 窗口方案（Wails v2 单窗口）

Wails v2 是单主窗口模型，桌宠用**同窗形态切换**近似（`internal/api/api_pet.go`）：

```text
主形态（1280×800 全功能） ⇄ 桌宠形态（260×300 置顶小窗）
```

- 进入桌宠：记录主窗位置/尺寸 → 缩到 260×300 → 置顶 → 最小尺寸同步为桌宠尺寸 → emit `pet:show`；
- 退出桌宠：恢复主窗尺寸/位置/最小尺寸（960×640）→ 取消置顶 → emit `pet:hide`；
- 窗口控制全部走 Wails runtime（`WindowSetSize/Position/AlwaysOnTop/MinSize`），Go 侧 `petMode` 状态机防重复切换。

**已知框架边界**：无边框 / 透明在 Wails v2 是创建期选项、运行时切不了，故当前桌宠仍是带边框小窗。真正的透明悬浮宠物需 Wails v3 多窗口（`application.NewWebviewWindow`）——升级决策另行立项。

## 2. 交互链路

- 召唤/收起：`PetSpaceView` 调 `POST /api/v1/pet/window/{pet|main}` → Go 切换窗口并 emit 事件；
- 路由联动：`App.vue` 监听 Wails `pet:show`/`pet:hide` → 切到 `/pet/desktop`（记忆原路由，退出后回跳）；该路由跳过 AppShell；
- 拖拽：`PetDesktop.vue` pointer 增量经 rAF 节流 → `shellBridge.invokeShell('pet.move')` → Wails 绑定 `PetMove(dx,dy)`；
- 双击收起：`invokeShell('pet.toggle')` → `PetToggleMode()`；
- 状态表情：每 2.5s 轮询 `GET /api/v1/pet/state`（返回状态字符串），前端映射到表情与配色（IDLE / WALKING / CLICKED / THINKING / SPEAKING）；
- 系统托盘：Win32 `Shell_NotifyIcon` + 弹出菜单（`tray_windows.go`，托盘菜单：打开主窗口 / 召唤·收起桌宠 / 隐藏主窗口 / 退出；双击图标=打开主窗口），动作经 `tray_bridge.go` 复用 `PetToggleMode()` 与 Wails 窗口 API。托盘在应用启动、gin 端口就绪后创建。

## 3. 状态与配置

- `internal/pet/controller.go`：`Controller` 维护当前状态，`GetPetState` 返回其字符串；事件驱动迁移表见该文件；
- 配置 `PetConfig`：sprite_id / scale / bubble_enabled，走 `pet_configs` 表 + `GET/POST /api/v1/pet/config`；
- sprite：`{home}/sprites/{id}.{ext}` + `pet_sprites` 表；上传走原生文件对话框单次选图 → Wails `UploadPetSprite` 绑定 → magic number 校验（PNG/JPEG/GIF/WebP 防扩展名伪装，≤5MB）→ 落盘注册后自动选中并在列表本地增量刷新；内置 sprite 不可删除；删除级联删磁盘文件；
- 预览：管理页与桌面窗口经 `/files/sprites/{id}`（URL 带时间戳参数防浏览器缓存旧图）；上传后管理页实时预览跟随下拉所选 sprite。

## 4. 界面

- `PetDesktop.vue`：优先渲染用户 sprite，否则内置 SVG 形象；按状态切换配色/动画（呼吸/眨眼/思考泡/说话嘴型）、显示气泡与状态徽章；
- `PetSpaceView.vue`：桌宠配置管理（sprite 管理/参数/召唤窗口）。

## 5. HTTP 接口

| 接口 | 方法路径 |
|---|---|
| 状态 | GET `/api/v1/pet/state`（返回状态字符串） |
| 配置 | GET `/api/v1/pet/config` · POST `/api/v1/pet/config/update` |
| 素材 | GET/POST `/api/v1/pet/sprites` · POST `/api/v1/pet/sprites/:id/delete` |
| 窗口 | POST `/api/v1/pet/window/{pet|main}` |

## 6. 错误码

| Code | 含义 |
|---|---|
| 9404 | sprite / 配置不存在 |
| 9405 | window not ready（ctx 未注入） |
