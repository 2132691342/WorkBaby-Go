# WorkBaby 文档

本目录描述 WorkBaby 的设计与实现现状。工程规范（技术栈锁定、分层约束、代码与注释规范）以根目录 `CLAUDE.md` 为准；两者冲突时以 `CLAUDE.md` 为准。

## 阅读路径

- **新人**：00 → 01 → 02 → 04（先建立全景、分层与内核认知）
- **后端**：01 → 02 → 03 → 04 → 05 → 06 → 07 → 08 → 09 → 10 → 11 → 16
- **前端**：13 → 16 → 07
- **运维 / 发布**：14 → 15 → 11 → 17

## 文档约定

- 只描述**现状**：设计、实现、接口与不变量。不写改动历史、不写与外部项目的对照、不写阶段计划。
- 模块文档与代码一一对应：表结构看 doc/02，端点看 doc/16，分层规则看 doc/01，测试地图看 doc/15。
- 改代码时同步改对应文档；文档与代码冲突时以代码为准，并立即修正文档。
