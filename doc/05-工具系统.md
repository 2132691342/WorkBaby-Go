# 工具系统

位置：`internal/tool/` 及各工具子包。所有「模型能调用的动作」都是实现了统一契约的工具。

## 工具契约

```go
type Tool interface {
    Name() string
    Description() string
    Schema() map[string]any          // JSON Schema，注册时自检
    Execute(ctx context.Context, args string) (string, error)
    Risk(args string) RiskLevel      // low / needs_approval / irreversible
}
```

`Registry` 负责注册、按名查找、schema 自检（`SelfCheckSchema` 在启动时执行，schema 非法直接启动失败）。工具可被 `system_settings` 单独停用。

## 内置工具

| 类别 | 工具 | 说明 |
|---|---|---|
| 文件 | `file_read` / `file_write` / `file_list` | 沙箱根内相对路径；写前落快照 + diff（可回滚） |
| 执行 | `exec` | 白名单 + 审批门；cwd 跟随会话工作区 |
| 网络 | `web_fetch` / `http_request` / `web_search` | 搜索用 DuckDuckGo，免 Key |
| 文档 | `doc_reader` / `archive` | Markdown / PDF / Office 解析与打包 |
| 纯函数 | `math_*` / `text_*` / `json_*` / `csv_*` / `hash_*` / `regex_*` / `datetime_*` / `encode_*` / `random_*` / `data_*` | 确定性计算，不走审批 |
| 技能 | `run_skill_script` | 执行技能包内脚本，解释器固定映射 |
| 记忆 | `memory_write` | 模型主动沉淀长期记忆 |
| 知识库 | `knowledge_search` | FTS5 检索 |
| 工作流 | `run_workflow` | 从对话触发工作流 |
| 委派 | `delegate_task` | 子 Agent 执行（见 04） |
| 交互 | `request_input` | 模型主动向用户要信息，run 暂停等回复 |
| 计划 | `todo` | 会话内待办清单，前端实时展示进度 |

## 工作区解析（RootResolver）

工具的沙箱根不是写死的，而是通过 `RootResolver(sessionID)` 在执行时解析：

```
会话绑定了外部目录 → 该目录
未绑定             → {home}/workspaces/{sessionID}
无会话上下文        → {home}/workspace
```

文件工具的相对路径、exec 的 cwd、技能脚本的执行目录、文件面板展示的目录都走同一解析，保证「Agent 写的文件 = 面板里看到的文件」。

## 执行沙箱

- `file_write` 的绝对路径必须落在沙箱根内（`filepath.Rel` 校验，防穿越）。
- `exec` 的 cwd 同样受信任体系约束：不在恒信任根内 → 走询问 → 用户批准后落盘记住。
- 技能脚本落盘到 `.workbaby/tmp` 后执行，进程 cwd 是工作区根。

## 审批与信任

- **审批门**：`Risk()` 返回 `needs_approval` / `irreversible` 的调用，在权限档不允许静默放行时转人工确认（见 04）。
- **目录信任**：`TrustService` 维护目录 → 状态（allow / ask / deny）与继承关系；恒信任根包括全局工作区树、内置运行时、知识库、附件目录。绑定外部工作区即登记 allow。
- **exec 白名单**：运行时从 `system_settings` 读取，设置页可改，重启即生效。

## 与文件变更 / 产出物的联动

- `file_write` 执行前读原内容落快照，写后算 diff：`file_changes` 表 + `chat:file-change` 事件；前端可在文件变更面板预览 diff 并一键回滚。
- 产出文件登记进 `artifacts`，前端经 `/files/**` 预览（媒体 / 文档 / 工作区文件统一走本地受管文件服务）。
