# 定时任务与通知通道

## 定时任务

`cron_jobs`：名称、spec（cron 表达式）、action（动作类型）、action_args（JSON）、enabled、last_run_at、last_status、next_run_at。

- 调度由 cron 引擎驱动；启动时按库内启用的任务注册，增删改后重建调度。
- 动作目前为 `run_workflow`：按 workflow_id 触发工作流执行（输入经 action_args 传入），执行结果回写 last_status / last_run_at。
- 支持手动触发一次（trigger）用于验证表达式与动作配置。
- 端点：

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /cron/jobs | 列表（含下次运行时间） |
| POST | /cron/jobs | 新建 |
| POST | /cron/jobs/:id/update | 更新 |
| POST | /cron/jobs/:id/delete | 删除 |
| POST | /cron/jobs/:id/trigger | 立即触发一次 |

## 通知通道

`channel_configs`：通道类型、启用状态、config_json、运行状态（stopped / running）、last_error、last_active_at；另有 `channel_message_logs` 记录收发日志。

| 类型 | 说明 |
|---|---|
| EMAIL | SMTP 发送（收件人、显示名等取自配置；SMTP 账号在设置页维护） |
| WEBHOOK | HTTP 回调（URL 等取自配置） |
| CONSOLE | 发送即写应用日志（本地调试用） |

- 敏感字段（如 SMTP 密码）落库前加密，列表返回时掩码；掩码值回写不会覆盖原值。
- 生命周期：start / stop 控制运行状态，失败落 last_error 与状态，便于前端定位。
- 支持「测试发送」验证配置连通性。
- 端点：

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | /channels | 列表（掩码后的配置 + 状态） |
| POST | /channels | 新建 |
| POST | /channels/:id/update | 更新 |
| POST | /channels/:id/delete | 删除 |
| POST | /channels/:id/start | 启动 |
| POST | /channels/:id/stop | 停止 |
| POST | /channels/:id/test | 测试发送 |
| GET | /channels/:id/messages | 收发日志 |

SMTP 与搜索等外部依赖配置集中在设置域：`GET/POST /settings/smtp`、`GET/POST /settings/websearch`、`GET/POST /settings/general`。

## 与其他模块的关系

- 工作流经 channel 节点发通知；定时任务触发工作流；二者共同构成「无人值守」链路。
- 通知发送失败只影响该次发送，写入 last_error 与日志，不打断工作流其余节点。

## 不变量

- 调度以库为真相源：重启后按启用状态重建，不依赖进程内残留。
- 敏感配置密文落库、掩码出参；掩码回写不覆盖密文。
- 每条通道有独立运行状态与错误信息，单通道故障不互相影响。
