# 记忆系统

位置：`internal/memory/`（策略与存储）+ `internal/capability/memory.go`（接入）。

## 三类记忆

| 类型 | 表 | 内容 | 形成条件 |
|---|---|---|---|
| 情景 Episodic | `memory_episodes` | 一次完整对话的摘要 + 全量 transcript + 触发器 | 分数 ≥ 0.30 |
| 语义 Semantic | `memory_facts` | 「用户偏好 / 明确要记住」类事实（subject / key / value / confidence） | 分数 ≥ 0.25 且命中偏好 / 记住表达 |
| 程序 Procedural | `memory_procedures` | ≥3 次工具调用去重后形成的步骤流 | 分数 ≥ 0.35 且有足够工具调用 |

另有一份**长期记忆** `MEMORY.md`（按会话分文件，上限 100KB），每轮 run 后追加「首条用户消息 + 末条助手回复 + 使用工具」的增量。

## 形成策略（FormationPolicy）

确定性打分，不调 LLM、不产生额外费用：

```
基础分（0.05 存在 + 用户/助手内容量各 0.05，上限 0.15）
  + 触发器加分：
      EXPLICIT_REMEMBER   「记住 / remember」      +0.55
      PREFERENCE_DETECTED 「我喜欢 / prefer」      +0.40
      MULTI_STEP_SUCCESS  多步工具全部成功          +0.35
      CORRECTION          用户纠正                  +0.30
      TOOL_SUCCESS        有工具成功                +0.20
      TURN_COMPLETE       完整问答（中英文问号）    +0.20
      USER_DISLIKE        用户表达不满              −1.0（一票否决）
```

设计意图：普通对话（基础 0.15 + 完整问答 0.20 = 0.35）能沉淀情景记忆，但不会「每轮一条」爆表；语义与程序记忆需要更明确的信号。

## 接入点

- **注入（Preload）**：run 前把 `MEMORY.md` 尾部（最多 4000 rune，按时间追加，最近内容最相关）+ 按本轮输入召回的相关条目注入上下文。
- **主动写入**：`memory_write` 工具让模型在对话中直接沉淀事实。
- **沉淀（Capture）**：run 结束后异步执行（独立超时，不阻塞响应），按策略落三类记忆并追加长期记忆。

## 开关

- 全局开关：`system_settings.memory.enabled`（缺省开启）。
- 注入与沉淀都受全局开关 + Agent 定义（`MemoryPolicy.Enabled` / `Formation`）双重约束。

## 检索

记忆检索基于 SQLite FTS5（情景摘要 / 事实 / 步骤的全文索引），`Recall(query, topK)` 返回按相关度排序的条目，供上下文召回与记忆中心的搜索框复用。

## 存放位置

- 会话绑定外部目录：`{workspace}/.workbaby/memory/{sid}/MEMORY.md`
- 未绑定：`{home}/memory/{sid}/MEMORY.md`

记忆中心页面提供三类记忆的列表、搜索、删除与统计，便于用户看清「AI 记住了什么」并手动清理。
