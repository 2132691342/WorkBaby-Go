# 数据模型

## 聚合根单文件多形态

一个聚合根一个文件，该实体的所有形态同居一处（`internal/domain/{name}.go`）：

| 后缀 | 用途 |
|---|---|
| `DO` | 数据库行（gorm 标签） |
| `REQ` | 入参 |
| `RESP` | 出参（snake_case JSON） |
| 枚举 / 常量 / 错误变量 | 同文件内定义 |

好处：改一个实体只看一个文件；跨层字段映射关系一目了然。

## 核心表

| 表 | 聚合根 | 说明 |

| `chat_sessions` | ChatSession | 会话：模型、参数、工作区路径、权限档、上下文预算 |

| `agent_checkpoints` | AgentCheckpoint | run 检查点（JSONL），断点续跑 |
| `run_records` | RunRecord | 执行记录索引（可跳转回放） |
| `ai_providers` | AiProvider | 模型供应商（apiKey AES-GCM 加密存储） |
| `token_usages` | TokenUsage | 每轮 LLM 调用用量明细（仪表盘唯一数据源） |
| `system_settings` | SystemSetting | 键值配置（exec 白名单、记忆开关等） |

## 本机数据目录

根目录：`%APPDATA%/WorkBaby`（可用环境变量 `WORKBABY_HOME` 重定向，便携模式友好）。

```
WorkBaby/
  config.yaml        应用配置（主密钥在此，首启随机生成）
  db/workbaby.db     SQLite（唯一持久化真源）
  logs/              运行日志
  runs/              每 run 一个事件 JSONL（回放 / 自动化消费）
  model.json         模型供应商配置源（存在则同步进 ai_providers 表）
  mcp.json           MCP server 配置源（存在则同步进 mcp_servers 表）
  workspaces/{sid}/  未绑定外部目录的会话默认工作区
  workspace/         全局兜底工作区（工具在无会话上下文时的落点）
  memory/{sid}/      未绑定会话的长期记忆 MEMORY.md
  snapshots/{sid}/   未绑定会话的文件写前快照
  knowledge/         知识库受管文件
  files/             上传附件
  sprites/           桌宠形象
  runtimes/          内置 Node / Python / PowerShell 解压产物
```

## 工作区沙箱 `.workbaby`

会话绑定外部目录时，所有过程数据收进该目录下的 `.workbaby/`，语义类似 `.git`：

```
{workspace}/.workbaby/
  memory/{sid}/MEMORY.md     本工作区会话的长期记忆
  snapshots/{sid}/           文件写前快照
  scripts/                   过程脚本
  output/                    产出物（报告 / 导出 / 生成文件）
  cache/                     可重建的派生缓存
  tmp/                       执行期临时文件（用完即删）
  .gitignore                 内容为 *，整棵树对 Git 不可见
```

约束：绑定工作区的那一刻由 `runtime.Sandbox.Ensure()` 建立整棵树，保证工具与模型始终有明确落点；系统级数据（日志 / 知识库 / 运行事件）不进工作区。工作区文件面板会把 `.workbaby/` 隐藏，不展示给用户。

## 存储语义

- DB 是唯一持久化真源；文件只承担三类角色：配置源（`model.json` / `mcp.json`，存在则向 DB 同步）、快照（`.workbaby/snapshots`、事件 JSONL）、导出产物。
- 敏感字段（API Key、SMTP 密码）AES-GCM 加密，密钥首启随机生成落 `config.yaml`。
- 时间戳统一毫秒整数（int64）。
