# WorkBaby 文档索引

WorkBaby 是一个 Windows 桌面端个人 AI 助手：本地优先（数据全部落本机）、能直接操作文件与执行命令、具备记忆 / 知识库 / 技能 / 工作流 / 定时任务等完整能力域。

技术栈：Go 1.25 + Gin + GORM + SQLite + Wails v2（后端），Vue 3 + TypeScript + Vite + Element Plus + Tailwind（前端）。
