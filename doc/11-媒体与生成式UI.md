# 11 · 媒体与生成式 UI

定义 `internal/media/`（媒体生成 + 产物存档）与 GenUI（生成式 UI）协议。
v1 媒体经离线占位生成（offline backend）保证离线可用；GenUI 协议预留。

---

## 1. 模块职责

- 统一媒体生成接口（image / video / audio / model3d / vfx）；
- 离线占位生成（offline backend，无需联网）；OpenAI 兼容 backend 预留；
- 产物存档：文件落 `{home}/media/`，元数据落 `media_artifacts` 表；
- 预设管理：Preset（参数模板）CRUD + 激活。

## 2. 文件结构

```
internal/media/
├── generator.go     # Generator 接口
├── service.go       # 预设 CRUD + 生成 + 产物编排
└── offline/         # 离线占位生成（PNG/GIF/WAV/GLB/sprite）
```

## 3. 数据契约

```go
// internal/domain/media.go
type MediaKind string  // image / video / audio / model3d / vfx

type MediaPresetDO struct {  // media_presets（参数模板）
    ID         string
    Name       string
    Kind       MediaKind
    Backend    string       // offline / openai
    Model      string
    ParamsJSON string
    IsDefault  bool
    Enabled    bool
}

type MediaArtifactDO struct {  // media_artifacts
    ID        string
    Kind      MediaKind
    PresetID  string
    Prompt    string
    FilePath  string       // 磁盘路径
    MimeType  string
    Width / Height *int
    FileSize  int64
}
```

## 4. 离线占位生成

`internal/media/offline/` 生成占位媒体，保证无网络时也能产出：

| Kind | 输出 |
|---|---|
| image | PNG 512×512 |
| video | GIF（多帧） |
| audio | WAV |
| model3d | GLB |
| vfx | PNG |

## 5. 产物存储

| 项 | 位置 |
|---|---|
| 文件 | `{home}/media/{id}.{ext}` |
| 元数据 | `media_artifacts` 表 |
| 前端访问 | `GET /files/media/{id}` |

## 6. GenUI 协议

模型回复 Markdown 中可包含 ` ```genui ` 代码块，块内 JSON 节点描述；前端 Markdown 渲染器识别后交给 GenUIRenderer 按类型渲染。

```typescript
type GenUINode =
  | { kind: "image", src: string }
  | { kind: "audio", src: string }
  | { kind: "video", src: string }
  | { kind: "card", title: string, body: string }
  | { kind: "table", columns: string[], rows: unknown[][] }
  | { kind: "chart", chartType: "bar"|"line"|"pie", data: unknown }
  | { kind: "code", language: string, content: string }
```

**安全**：src 必须 `/files/` 前缀（本地受控路径）；iframe 不提供；模型输出非法 JSON 时前端降级为代码块。
