# 14 构建与分发

## 定位

Wails v2 应用构建：单 exe + 内嵌前端 dist + AssetServer 文件服务 + NSIS 安装包 / 便携模式。

## 设计要点

- **embed 前端 dist**：`main.go` 通过 `//go:embed all:frontend/dist` 把构建产物打进二进制，单文件部署
- **AssetServer 双 Handler**：`/files/**` 走 `FileServer`（本地受管资源），其余回退到 `http.FS(assets)`
- **NSIS 安装包**：`wails build -nsis` 生成 Windows 安装器（含开始菜单、卸载注册）
- **便携模式**：二进制同目录存在 `.portable` 标记 → 数据目录落在 exe 旁（不写 `%APPDATA%`），适合 U 盘 / 临时环境
- **内置运行时**：node / python / powershell 离线 zip 在 `runtimes/`，首次运行解压到 dataHome（供 Skill 脚本直跑）
- **单实例**：`internal/singleinstance/` 命名互斥 + 本地 TCP IPC；二次启动把文件路径转主实例后退出

## 核心契约

### 构建命令

| 命令 | 输出 |
|---|---|
| `wails dev` | 开发模式（热重载） |
| `wails build -nsis -ldflags "-s -w" -trimpath` | 生产 exe + NSIS 安装包 |
| `go build ./...` | 后端编译检查 |
| `go test ./...` | 后端测试 |
| `npm test` / `npx vitest run` | 前端测试 |
| `npm run build` | 前端生产构建（写入 `frontend/dist/`） |
| `npx vue-tsc --noEmit` | 前端类型检查 |

### NSIS 模板

`build/windows/installer/project.nsi`（由 wails init 生成）+ 自定义 banner / icon。

### 资源目录

| 路径 | 用途 |
|---|---|
| `build/windows/` | Windows 资源（icon / manifest） |
| `runtimes/` | 内置 node / python / powershell zip + manifest.json |
| `assets/` | embed 进二进制的资源（默认 sprite / icon） |

### 便携模式

```go
func Resolve() (*Paths, error) {
    if _, err := os.Stat(".portable"); err == nil {
        home = filepath.Join(exeDir, "WorkBaby")
    } else {
        home = filepath.Join(appData, "WorkBaby")
    }
}
```

### 内置运行时 manifest

`runtimes/manifest.json`：

```json
{
  "runtimes": [
    { "id": "node", "version": "20.x", "archive": "node-v20-x64.zip", "exe": "node.exe" },
    { "id": "python", "version": "3.12", "archive": "python-3.12.tar.gz", "exe": "python.exe" },
    { "id": "powershell", "version": "7.x", "archive": "powershell-7-x64.zip", "exe": "pwsh.exe" }
  ]
}
```

首次使用某 runtime 时解压到 `{dataHome}/runtimes/<id>-<ver>/`，SkillRunTool 把其 bin 目录注入 PATH。

## 关键流程

### 首次启动数据目录初始化

```
main.wails.Run → startup(ctx):
  Paths.Resolve() → home
  EnsureDir(home, home/db, home/logs)
  Handler.Startup:
    Viper 加载 config.yaml + env
    DB.Open → GORM AutoMigrate → FTS5 创建
    EventLog + Registry + ToolRegistry 装配
  srv.Start() → gin 随机端口
  Handler.EmitReady(port)
  Tray.Start(ctx, app)
  flushPendingOpenFile()
```

### 构建后分发

```
wails build → build/bin/WorkBaby.exe
            → build/bin/WorkBaby-amd64-installer.exe
同目录附：
  - .portable（可选，便携模式）
  - runtimes/（按需）
```

## 约束

- 二进制跨 Windows 平台（amd64 / arm64）；其他平台仅供开发
- `wails build` 必须在 frontend `npm run build` 之后；wails 自动调用
- `ldflags "-s -w"` 去符号表与 DWARF；`-trimpath` 去构建路径（防泄漏）
- 单 exe ≤ ~30MB（含前端 dist）；runtime 按需解压（不进 exe）
